# RVMC · Programa de la reunión

Versión web de la app RVMC para preparar el programa de la reunión Vida y Ministerio Cristianos: asignaciones por turnos, programa en PDF, formularios S-89 y mensajes de WhatsApp.

Los datos (nombres, móviles y semanas) **no están en este repositorio**: se guardan solo en el navegador de cada dispositivo. Para pasarlos de un dispositivo a otro se usa una copia de seguridad (`Copia RVMC ….json`), compatible con la app de Mac, iPad e iPhone.
